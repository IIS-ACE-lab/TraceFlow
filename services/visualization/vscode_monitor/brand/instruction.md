Upload services/visualization/vscode_monitor/brand/traceflow-social.png. GitHub has no separate repository icon; the image people see for a repo is its social preview. It appears when the repo link is shared (Slack, X, LinkedIn, Teams) and on some GitHub cards.

To set it: on github.com, open the repo → Settings → General → Social preview → Edit → Upload an image… → choose services/visualization/vscode_monitor/brand/traceflow-social.png. The file meets GitHub's requirements: 1280×640, which is the recommended size, PNG, and well under 1 MB.
